# Proposals

When the spec in `docs/` is wrong, unclear or impossible, the coding agent writes `NNN-short-title.md` here:

```markdown
# NNN: Title
Status: PROPOSED | ACCEPTED | REJECTED
## Problem
## Options (with trade-offs)
## Recommendation
## Impacted docs / code
```
Only the product owner or architect changes the status. Accepted proposals are merged into the docs by the architect.
